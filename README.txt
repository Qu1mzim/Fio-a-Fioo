FIO A FIO — Projeto do site

COMO ABRIR
1. Extraia a pasta fio-a-fio.
2. Abra o arquivo index.html no navegador.

ESTRUTURA
- index.html: conteúdo e estrutura do site.
- css/style.css: visual, cores, responsividade e animações.
- js/script.js: abas dos tipos de cabelo, menu mobile, tema claro/escuro e animações.

OBSERVAÇÃO
O site usa Google Fonts quando há conexão com a internet. Se estiver offline,
serão utilizadas fontes alternativas instaladas no dispositivo.
